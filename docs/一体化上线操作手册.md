  1. **轨道 A · 素材剪辑**：用户提供原始视频素材，我方完成剪辑、字幕、封面、标题与话题，输出各平台适配画幅。
  2. **轨道 B · 型号生成视频**：用户只给产品型号（与想突出的功能点），由 Seedance 2.5 按分类脚本生成短视频；发布前人工核对机型、参数、价格与保修口径，画面必须与实物一致。
- **成交环节**：在线下门店或微信私聊完成；价格、库存、保修、发票、付款方式等交易条件由双方在电话/微信中当面确认，网站与小程序不参与收款、不记录订单。
- 后端现有接口清单中不存在购物车、下单、支付、订单功能；后续若决定开通线上成交，需另行评估微信支付商户号、订单表、交易类目资质与合规要求，不在当前规划内。

## 二、后端上线步骤（Cloudflare Pages 现有项目）

### 1. 新表结构（已自动建表，无需手动执行）

后端在首次调用 `/api/wechat-login`、`/api/wechat-bind`、`/api/channel-track` 时，会通过 `functions/_lib/ensure-schema.js` 幂等执行 `CREATE TABLE IF NOT EXISTS` 自动补齐两张新表；`schema.sql` 仅作为结构留档，本地或 CI 无需再用 wrangler 手动执行 D1 迁移。

`schema.sql` 里新增的两张表：

- `external_identities`：记录各端 `openid / unionid` 与 `users.id` 的绑定，`source` 取值：`miniprogram`（小程序）、`official`（公众号）。
- `channel_tracks`：记录线索来源平台、内容形式、活动编号、落地时间，用于渠道复盘。

### 2. 配置环境变量（Secret）
Cloudflare Pages → 项目 `wnsm-store` → Settings → Environment variables，配置以下 4 个 Production 变量：

| 变量名 | 来源 | 用途 |
|---|---|---|
| `WX_MP_APPID` | 小程序后台「开发管理 → 开发设置」AppID | 小程序 code2session |
| `WX_MP_SECRET` | 小程序后台 AppSecret | 小程序 code2session |
| `WX_OA_APPID` | 公众号后台 AppID | 公众号网页授权、JS-SDK 签名 |
| `WX_OA_SECRET` | 公众号后台 AppSecret | 公众号 access_token 与 jsapi_ticket |

在这四个变量配置完成前，`/api/wechat-login` 与 `/api/wx-jsapi-signature` 返回 503 并提示先使用手机号登录，不会影响现有网站功能。

### 3. 接口契约（与小程序前端已对齐）

| 接口 | 方法 | 说明 | 与现有体系的关系 |
|---|---|---|---|
| `/api/products` | GET | 按身份返回展示价 | 原有，未改逻辑 |
| `/api/me` | GET | 当前登录用户 | 原有，token 头适配后小程序同样可用 |
| `/api/login` | POST | 手机号 + 密码登录，响应新增 `token` 字段 | 原有，仅扩展响应体 |
| `/api/register` | POST | 注册，响应新增 `token` 字段 | 原有，仅扩展响应体 |
| `/api/logout` | POST | 退出 | 原有 |
| `/api/wechat-login` | POST | `{ code, source: miniprogram\|official }`；已绑定直接登录并回 `user + token`；未绑定回 `needBind: true, openid, unionid` | 新增 |
| `/api/wechat-bind` | POST | 登录态下绑定 `{ source, openid, unionid, nickname?, avatar?, channel? }` | 新增 |
| `/api/channel-track` | POST | `{ source, medium?, campaign?, referrer? }`，source 取值 `wechat_mp / wechat_oa / wechat_channels / web / douyin / kuaishou / xhs / direct` | 新增 |
| `/api/wx-jsapi-signature` | POST | `{ url }`，返回 `appId, timestamp, nonceStr, signature` | 新增 |

### 4. 小程序登录流程（后端已支持两种路径）

1. **已绑定微信**：`wx.login()` 取 code → `/api/wechat-login` → 后端 code2session 得到 openid → 命中 `external_identities` → 直接创建会话回 token。
2. **首次未绑定**：接口返回 `needBind: true` 与 openid/unionid → 前端引导手机号登录/注册成功 → 调 `/api/wechat-bind` 完成绑定；之后再走路径 1。

公众号网页授权复用同一接口，`source: 'official'`；同一微信开放平台主体下，小程序与公众号返回同一个 `unionid`。

## 三、小程序上线步骤

### 1. 注册与备案（前置条件）
- 用营业执照在 `mp.weixin.qq.com` 注册**企业或个体工商户**主体小程序。即便当前定位不做在线成交与收款，个人主体仍受限：可选类目窄、不能绑定公众号与视频号、不支持开放平台 unionid 互通，名称也不能使用经营类字样，因此不采用个人主体。
- 完成小程序备案（工信部备案，当前强制要求）。
- 建议同时注册**服务号**（订阅号没有网页授权、客服消息、模板消息能力），两者绑定到同一个**微信开放平台账号**以拿到 unionid。

### 2. 导入工程
- 打开微信开发者工具 → 导入目录 `miniprogram/`。
- 把 `project.config.json` 里的 `appid` 替换为注册后的小程序 AppID。
- `utils/api.js` 中 `BASE_URL = 'https://wnsm.store'`，上线前确认该域名已在小程序后台「开发管理 → 开发设置 → 服务器域名 → request 合法域名」中添加（必须 HTTPS）。

### 3. 本地真机预览
- 微信开发者工具 → 真机调试，确认报价列表、登录注册、搜索筛选、联系电话都能走通线上接口。
- 微信一键登录在未配置 `WX_MP_APPID / WX_MP_SECRET` 时会提示先手机号登录，属预期行为。

### 4. 提交审核
- 服务类目：优先选「工具」或「商业信息/信息查询」等与报价展示匹配的类目；本小程序不做在线交易、不接微信支付，**不要选电商平台、电商导购、商家自营 3C 数码等交易类目**。
- 小程序「关于我们」页内置《服务规则》与《隐私政策》，并展示个人微信（兰州蜗牛数码）二维码、公众号二维码与电话；口径与官网 `privacy.html`、`rules.html`、`service.html` 保持一致；登录/注册页点击协议名可跳转到该页。上传体验版 → 提交审核 → 发布。
- 提审材料中说明：小程序仅展示渠道报价与联系方式，咨询引导到电话/微信，无购物车、下单、支付入口。

## 四、公众号与视频号配置清单

### 公众号
1. 后台 → 自定义菜单：三个一级菜单分别指向「小程序报价页」「关于我们（可挂 H5 官网页面）」「联系客服」；关于页 H5 / 图文末尾统一展示个人微信（兰州蜗牛数码）二维码与电话。
2. 图文消息内嵌小程序卡片，直接跳小程序对应报价页。
3. 需要自定义分享标题/封面时，页面在加载后调 `/api/wx-jsapi-signature`，再调用 `wx.config` 注入。
4. 公众号网页授权入口 H5 可复用官网现有页面，加 URL 参数 `source=wechat_oa&campaign=xxx` 进 `/api/channel-track`。

### 视频号
1. 视频号助手注册并与公众号、小程序保持同一主体并完成绑定。
2. 视频号只做展示获客：复用两条生产线产出的功能性分类短视频，不在视频号开通小店、不挂载线上商品、不做直播带货；话术引导用户从主页进入公众号 / 小程序查看完整报价，个人微信二维码与微信号只在公众号、小程序、官网页面展示，不放在视频号主页与视频里。
3. 视频号主页挂公众号链接与小程序入口；官网经公众号菜单中转，不在视频号直挂官网外链。

## 五、外部平台（抖音 / 快手 / 小红书）合规做法

这些平台不允许站内引导到外部网站、微信或第三方小程序，也无法把站内用户直接写入你的 D1，因此**不做跨端账号打通**；按当前定位，这些平台**只做功能性分类短视频引流、不开店、不做直播带货、不做站内成交**，统一按以下方式协同：

1. **分类短视频引流**：只发布按品牌/机型/功能卖点/选购避坑组织的短视频（小红书可叠加选购图文），**不开通抖音小店 / 快手小店 / 小红书店铺**，不上架站内商品、不引导站内下单或购买，现阶段不开直播带货。这些平台**不能直接挂公众号、小程序、官网、个人微信链接**；客户先通过官方联系方式组件 / 留资入口沟通，或主动搜索"兰州蜗牛数码"进入公众号、小程序、官网，再由承接页面引导添加个人微信。
2. **内容两条生产线**：
   - 轨道 A：用户提供原始视频素材 → 我方剪辑、加字幕/封面/标题/话题，按 9:16（抖音/快手）、3:4（小红书）输出。
   - 轨道 B：用户给出产品型号与功能点 → Seedance 2.5 生成分类短视频；发布前人工核对机型、外观、参数、价格与保修口径，确保画面与实物一致，不虚构配置与促销。
3. **弱归因**：各平台私信/留资后由人工加到企业微信，添加时标注来源渠道；后续 `/api/channel-track` 记录 `source=douyin / kuaishou / xhs` 等，用于复盘引流效果。
4. **红线**：视频、评论、私信、主页简介里不出现微信号、手机号、外部链接、二维码、"加微信/V我/主页有微"等导流字样及其变体，也不出现公众号名称引导跳转、小程序名称引导跳转与官网网址；不虚构原价、不做虚假比价。仅可使用平台官方允许的联系方式组件或主页留资入口。
